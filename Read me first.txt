=========
SOULBOUND
=========

EXTRACT THIS ARCHIVE BEFORE RUNNING THE GAME.

Do not run the program from inside the zip. Windows will let you double click it there,
but it unpacks the program on its own into a temporary folder, without the rest of the
files, and the game stops with an error about a missing Mods folder.

Extract the whole archive to a folder somewhere, then run it from there. The "Mods" and
"Default" folders have to sit next to the program.

On macOS, read "How to run Soulbound on Mac.txt" as well. The application will not open
until it has been marked executable.


WHAT IS IN THIS BUILD
---------------------

Not a game yet. What exists is the loop the game hangs off: name your character, pick a
boss, fight it, and come back to the list with it marked cleared and your time recorded.

The bosses are placeholders, a monster with no sprite and an attack that fires nothing, so
a fight is over in seconds. The last entry in the list, "Stress Test", is not a boss at
all. It is a measuring instrument: three turns of fixed length that report how long they
took, used to check the fight keeps its own time on slow hardware. Escape leaves it.

Every screen is rebuilt at v0.6, and the first real boss is v0.7.


WHERE YOUR SAVE LIVES
---------------------

Windows   %USERPROFILE%\AppData\LocalLow\PaperTrail\Soulbound\
macOS     ~/Library/Application Support/PaperTrail/Soulbound/
Linux     ~/.config/unity3d/PaperTrail/Soulbound/

That folder holds your name, your boss records and your settings.

If you are reporting a crash, the engine log is the useful thing to attach. Unity does not
put it in the same place on every system:

Windows   the folder above, as output_log.txt
Linux     the folder above, as Player.log
macOS     ~/Library/Logs/PaperTrail/Soulbound/Player.log
